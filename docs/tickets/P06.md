# P06 — saved stories 2.0

Depends on T15. Collections/tags, read-later with reminder, per-story notes,
reminders. A save is a bookmark only (ID), no story text on the device; offline
reading is out of scope (ADR-044, owner decision 2026-10-04). Acceptance: all
local-first, survives restart, deletion removes note/collection/reminder,
withdrawn stories show as unavailable (corrections/retractions always current
because nothing is copied).
