# X5 — official X updates in reader surfaces

**Depends on:** X1–X4, T14/T15, accepted ADR-037 and reviewed X accounts.

Use the existing approved-story pipeline. Give readers a clearly labeled way
to find X-derived stories in the owner-selected app placement. A card opens
the same bilingual story detail as news; source attribution links to the
specific X post. Do not expose raw post text, media, an unreviewed timeline,
or a new client-side X API integration.

Acceptance: only published statuses appear; `DISABLED` sources and sensitive
unapproved stories do not. Empty, loading and failed states are honest. Long
EN/TE copy, light/dark, small-phone and screen-reader journeys are verified.
Existing news browsing and source links still work. Admin source approval,
stable user IDs, rights evidence, X API access and budget are required before
real accounts are enabled. Public API, native app and web parity are scoped
after ADR-037 chooses reader placement.
