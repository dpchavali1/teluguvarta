# T22 — Free-tier privacy gate, rate limiter, request counter

**Depends on**: ADR-015 (accepted), Spike 1 (graded). Numbering note:
`docs/plans/gemini-hetzner-telugu-plan.md` calls this scope "T23" and uses "T22" for
infra; ADR-015 and the product owner call it T22. This file follows ADR-015. The
plan's infra/backup work is **not** in this ticket.

## Goal

Make it structurally impossible for the Gemini free tier to receive a story that
is not explicitly cleared, and keep free-tier traffic inside confirmed quotas.

## Scope

- `sources.category` (nullable text, migration): the source's configured category.
- `stories.privacy_decision` (`FREE_TIER_ALLOWED | RESTRICTED | UNKNOWN`, default
  `UNKNOWN`, CHECK-constrained, migration): persisted once, read by every dispatch.
- `app/ai/privacy.py`: deterministic pre-classifier (no model call). Starts at
  `UNKNOWN`; `FREE_TIER_ALLOWED` needs category on `ALLOWLIST_V1`
  (`entertainment`, `sports`, `community_events`) **and** no restricted signal;
  a restricted signal gives `RESTRICTED`. `tighten()` may only move toward
  `RESTRICTED`, never loosen.
- `app/ai/ratelimit.py`: per-model token bucket at confirmed RPM; per-model RPD
  counter over the Pacific quota day (`budget.quota_day_start`) read from
  `ai_call_log`, unavailable calls included.
- Gateway enforcement: a route to provider `gemini` **raises**
  `FreeTierViolation` unless the story's persisted decision is
  `FREE_TIER_ALLOWED`, and always when the text is editor-authored. Applies to
  escalation dispatches too.
- A quota miss or provider 429 returns `GatewayStatus.DEFERRED`: not a failure,
  not a circuit-breaker trip; the call is still recorded.

## Out of scope

Changing `ROUTING` (no task is routed to Gemini here), paid-tier rates, wiring the
decision into `generate.py`/`translate.py` (follow-up ticket; the gateway guard
already makes an unwired call raise rather than leak), infra/backups.

## Acceptance criteria

- No category, unlisted category, or restricted signal never yields `FREE_TIER_ALLOWED`.
- `tighten()` cannot loosen; `UNKNOWN`/`RESTRICTED` and missing story id never
  reach Gemini (raises); editor-authored text never reaches Gemini.
- Bucket refuses above RPM and refills; RPD counts only the current Pacific day,
  per model, including `UNAVAILABLE`/`DEFERRED` rows.
- 429/quota exhaustion gives `DEFERRED`, recorded, no exception.
- Migration applies on a clean DB; existing tests still pass.
