# T15 — Mobile MVP

**Depends on**: T12, T13.

## Goal

Ship iOS + Android from the one Expo/React Native codebase, sharing the
core feed and contract types with web.

## Scope

- Screens per §9.2: onboarding, home, topic/category feeds, story detail,
  search, saved, notifications inbox, settings, language switch, privacy +
  delete account.
- Onboarding exactly per §3.1: every step skippable, "continue without
  login" always available and never blocking browsing; optional
  country/home region/city; optional life stage (International Student,
  Graduate/OPT, Professional, Family/Parent, Other); conditional student
  sub-questions (study country/region/metro, degree level, student topics —
  no university name or immigration-document data collected); interest
  selection; language preference; notification preferences with independent
  per-topic toggles, quiet hours, max alert frequency, and a way to disable
  all notifications without disabling news access.
- Story card and share behavior match T14's web implementation exactly
  (same canonical URLs, text-only per ADR-002, always a visible link to the
  actual source) — use the native OS share sheet.
- Use `packages/contracts` types and, where practical, shared logic/
  components from `packages/ui`/`packages/domain` rather than duplicating
  web's implementation.
- Accessibility: equivalent accessible behavior to web's WCAG 2.2 AA target
  — dynamic text size, screen-reader labels, ≥44pt touch targets.

## Acceptance criteria

- App builds and runs for iOS and Android from the same codebase.
- Onboarding can be fully skipped and the user still reaches a working feed.
- Notification preference toggles persist and are independently
  controllable per the spec's list (topic, breaking, daily briefing, quiet
  hours, max/day, disable-all-without-losing-news-access).
- Sharing a story from mobile produces the same canonical URL/preview
  behavior verified in T14.
- Mobile smoke/E2E test covers onboarding-skip → home → story open → save →
  share.
