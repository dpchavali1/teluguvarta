# P01 — persona presets

Depends on S1/S2, UI16. Presets (Student F-1/OPT/H-1B, H-1B/Green Card holder,
Family back home, Farmer, Investor, Techie, Movie fan) each set explicit topics,
alert switches and quiet-hour defaults on the existing preference/subscription
store; users may combine presets and edit afterwards. Presets never infer or
store a persona server-side beyond existing subscriptions (ADR-005, §3.1).
Offered in onboarding and Settings. Acceptance: applying/removing a preset only
changes the choices it owns; student preset reuses S1/S2, not a parallel path;
web+mobile parity; tests, typecheck, bundle.
