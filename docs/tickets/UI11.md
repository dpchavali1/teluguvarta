# UI11 — App reader settings and deletion feedback

T14/T15 follow-up under accepted ADR-009/010/014. Depends on UI10
implementation; device evidence is tracked separately.

Group existing reader preferences clearly and add accessible headings. Preserve onboarding skip and M1–M6 behavior. Do not report server deletion success on failure; preserve the identity for retry and report local-clear failures truthfully.

Acceptance: scoped typecheck/tests and web build or Expo export as applicable.
Record state/visual/a11y checks and remaining device/deployment limitations.
