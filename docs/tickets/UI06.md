# UI06 — Web saved recovery

T14 follow-up under accepted ADR-009/010/014. Depends on UI05.

Clarify on-device scope and unavailable bookmarks, keep browse/retry paths reachable and report storage read failures without claiming an empty library. Preserve bookmarks on API failure. Privacy/deletion/correction links remain unchanged.

Acceptance: scoped lint/typecheck/tests/build; browser populated/empty/error
states and light/dark EN/TE responsive checks. Record device/deployment limits.
