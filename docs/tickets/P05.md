# P05 — My Edit feed

Depends on ADR-040 (must be accepted), T16, P01, P03. Home section ordered by
explicit signals only (follows, mutes, saves, 'show less like this') using the
deterministic ranking; sections: For you, Top 5 today, Because you saved X.
'Why am I seeing this?' on every story; preferences page to view/reset all
signals. No behavioral tracking. Acceptance: identical inputs give identical
order; mutes cannot hide breaking/immigration/legal/financial; tests.
