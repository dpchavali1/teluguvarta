# T14 — Web MVP

**Depends on**: T12, T13.

## Goal

Ship the public Next.js site consuming the real API/contract, completing
the vertical slice on web.

## Scope

- Pages per §9.1: home/feed, story detail, topic page, country/region page,
  search results, saved, about, privacy/terms/AI-disclosure/copyright-
  takedown/corrections pages, account deletion, 404/500.
- Story card per §3.3 **as restricted by ADR-002**: original editorial
  headline, country/topic/impact labels, 2-4 sentence original summary,
  audience-specific "why this matters," a prominent, clickable link to the
  actual source article/post (this is the primary read-more mechanism, not
  optional), visible correction/update indicator, one-tap EN⇄Telugu toggle,
  save action. **Text-only** in this phase — no source photo, no branded
  Share Card image (ADR-002 defers that feature).
- Native share with Copy Link fallback (§3.3): share the canonical story
  URL (never copied source text), language-aware title/description, and a
  text-only social preview (no image) per ADR-002. Populate social preview
  metadata from `GET /v1/stories/{slug}/share-meta`.
- SEO: SSR/ISR via Next.js, correct meta tags, sitemap, canonical URLs.
- Accessibility target: WCAG 2.2 AA (§3.4) — dynamic text size, high
  contrast, screen-reader labels, keyboard navigation, reduced motion.
- Use only types from `packages/contracts` for API data — no hand-rolled
  duplicate types.

## Acceptance criteria

- Every page in §9.1 exists and renders real data from the API for at least
  one seeded story.
- Sharing a story produces a canonical URL with correct, text-only preview
  metadata (per ADR-002, no preview image in this phase).
- Every published story's card has a working, visible link to the actual
  source article/post.
- A retracted or corrected story visibly shows its updated/corrected state.
- Automated accessibility check (e.g. axe) passes on home and story pages
  with no critical violations.
- Legal pages listed in §5.4 are all present and reachable from the footer.
