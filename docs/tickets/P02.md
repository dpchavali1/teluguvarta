# P02 — smart alerts

Depends on UI16, T17-firebase. Add per-topic urgency (breaking only / digest /
off); morning and evening digest at a chosen local time as one notification;
keyword/entity follows; dual-timezone quiet hours (home + residence); update
alerts for saved stories when a correction or new fact is published. All via
existing idempotent push jobs, bounded retry, and the daily cap. Immigration,
legal, financial and breaking items stay human-reviewed before any alert.
Quiet hours stay whole-hour unless the API changes. Acceptance: digest dedupes
against already-sent alerts; keyword follows are bounded in count and length;
job tests for idempotency; device push proof is a separate gate.
