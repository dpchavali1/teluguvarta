# T01 — Initialize monorepo

**Depends on**: nothing. This is the first ticket.

## Goal

Stand up the monorepo skeleton with working CI, so every later ticket has a
place to land code and a safety net.

## Scope

- Confirm/create the layout in `docs/SPEC.md` §11:
  `apps/{web,mobile,api,admin}`, `packages/{contracts,ui,config,ai,domain}`,
  `infra/{migrations,scripts}`, `tests/{fixtures,e2e}` (directories already
  exist as placeholders from initial scaffolding — fill them in).
- Choose and set up a JS/TS package manager workspace (pnpm workspaces
  recommended: cheap, no extra daemon/build-system infra, consistent with
  "avoid unnecessary operational complexity"). Record the choice in an ADR
  only if it's contested later — this one is low-risk enough to just do.
- `apps/api` gets a minimal Python project (pyproject.toml, FastAPI + Uvicorn
  dependency, a `/health` endpoint) — this is the T01-equivalent foundation
  the master prompt refers to, not full API surface (that's T04+).
- Shared tooling: root `package.json`, `pnpm-workspace.yaml`, shared
  `packages/config` with base `tsconfig.json` and ESLint/Prettier config
  consumed by `apps/web`, `apps/mobile`, `apps/admin`.
- CI (GitHub Actions or equivalent under `.github/workflows/`): on every
  push/PR run — install, lint, typecheck, and `pytest`/`vitest` (even if just
  smoke tests initially) for whichever workspaces have code. Keep it fast;
  don't add build/deploy steps yet (T25/deployment is later).
- Root `README.md` update: how to install, run, and test the monorepo
  locally (link to `docs/` for anything deeper — don't duplicate content).

## Out of scope

Do not implement the DB schema (T03), OpenAPI contracts (T04), or any
business logic. Do not add Docker/deployment config unless it's needed to
make local dev or CI work — that's T02/T25 territory.

## Acceptance criteria

- `pnpm install` (or chosen equivalent) succeeds from repo root.
- Each `apps/*` workspace has a minimal valid entry point that at least
  boots (Next.js default page, Expo default screen, FastAPI `/health`
  returning 200, admin Next.js default page) — placeholder is fine.
- CI runs on push and passes on a clean checkout.
- `docs/tickets/README.md`/`PROGRESS.md` updated to mark T01 done.
