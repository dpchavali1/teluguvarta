# T07 — First source adapters

**Depends on**: T06.

## Goal

Prove the adapter contract with real, low-risk sources before building the
generic ingestion worker around it.

## Scope

- Per §6.1 and ADR-002: seed 3-5 sources approved at `LINK_ONLY` — publicly
  readable sources (government feeds, mainstream news sites, official
  community sites) whose terms don't prohibit linking/factual summarization.
  No source needs a licensing agreement for this tier. Get rights evidence
  recorded via T06 before writing the adapter, not after.
- Implement the adapter contract from §6.3 for each seeded source:
  `fetch() -> RawItems`, `normalize(raw_item) -> NormalizedItem`,
  `validate(normalized_item) -> ValidationResult`,
  `emit(normalized_item) -> SourceItem`. Put this in a shared adapter
  interface (e.g. `packages/domain` or an `apps/api` module) so future
  adapters (including X in X2) implement the same shape.
- Test fixtures under `tests/fixtures/` with recorded sample responses per
  source, so adapter tests don't hit the network in CI.
- Do not wire these into a scheduled worker yet — that's T08. This ticket
  proves `fetch → normalize → validate → emit` works for real data,
  callable manually/in tests.

## Acceptance criteria

- Each of the 3-5 seeded sources has recorded rights evidence (not
  `DISABLED` unless that's the deliberate test case) and a working adapter
  with fixture-based tests covering fetch/normalize/validate/emit.
- A `SourceItem` row is correctly created per adapter run against fixtures.
- No adapter makes a live network call during CI test runs.
