# UI05 — Web search recovery

T14 follow-up under accepted ADR-009/010/014. Depends on UI04.

Show returned count as shown results and explicitly note the 20-result limit at capacity. Keep query and search form on API failure, with retry and topic browse links. Cover empty/failure/full results. Backend pagination/relevance remains separate.

Acceptance: scoped lint/typecheck/tests/build; browser populated/empty/error
states and light/dark EN/TE responsive checks. Record device/deployment limits.
