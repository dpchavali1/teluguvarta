# UI02 — Discoverable website topic scrolling

T14 follow-up under ADR-014. Depends on UI01 (done locally).

Keep every topic/URL and active state. Replace unconditional masking with
native horizontal scrolling and labelled previous/next controls that appear
only on overflow. Controls have 44px targets and respect reduced motion.
Resize, route changes and keyboard focus reveal the relevant link.
Acceptance: no controls on short lists, correct disabled states at each edge,
last/active topic reachable, no page overflow; scoped checks and browser QA.
