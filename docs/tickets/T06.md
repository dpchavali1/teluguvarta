# T06 — Source registry

**Depends on**: T03, T05.

## Goal

Admin-manageable registry of content sources with the rights gate enforced
as a real control, not a formality.

## Scope

- CRUD for `Source` (fields per §6.2: `id, name, base_url, feed_url,
  source_type, country, language, rights_status, rights_evidence_url,
  rights_reviewed_at, reviewer, refresh_minutes, active, fail_count,
  last_success_at, last_error_at`) via `/v1/admin/sources`.
- Rights evidence record: URL, terms/policy URL, reviewed date, reviewer,
  permitted fields, restrictions, territory, expiration if any, evidence
  notes (§5.1). Enabling a source (moving off `DISABLED`) must require this
  evidence to be present — enforce in the API layer, not just the UI.
- Per-source kill switch (`SOURCE_<id>_ENABLED` style flag or a DB `active`
  column wired to the same effect) and the global kill switches from §15:
  `AUTO_PUBLISH_GLOBAL`, `AUTO_PUBLISH_CATEGORY_IMMIGRATION`.
- **ADR-002 (source-rights approval policy) is already accepted** — see
  `docs/adr/ADR-002-source-rights-approval-policy.md`. This build phase only
  allows moving a source from `DISABLED` to `LINK_ONLY`; the admin API must
  reject attempts to set `LICENSED_METADATA`/`LICENSED_REPURPOSE` (return a
  clear error, e.g. `RIGHTS_TIER_NOT_ENABLED`) until a future ADR supersedes
  ADR-002. Still decide and record, as part of this ticket: who/what role
  can move a source to `LINK_ONLY`, whether a second approver is required,
  and how evidence expiration is tracked — add these as an addendum note in
  ADR-002 rather than a new ADR.
- Health state fields (`fail_count`, `last_success_at`, `last_error_at`)
  visible via the admin API — actual population happens in T08, but the
  schema/API contract must exist now.

## Acceptance criteria

- A source cannot be enabled (rights_status changed off `DISABLED`) without
  rights evidence fields populated — test this rejection path.
- A request to set `rights_status` to `LICENSED_METADATA` or
  `LICENSED_REPURPOSE` is rejected with a clear error per ADR-002, even with
  valid evidence — only `DISABLED` and `LINK_ONLY` are reachable in this
  build phase.
- Admin API lets an authorized editor list/create/update sources.
- Every admin mutation here writes an `AuditEvent`.
